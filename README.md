## 🛠️ Архитектура проекта и Спецификация Гибридного API

В рамках данного домашнего задания реализован продвинутый интерфейс для системы управления облачными серверами (Cloud Dashboard). Проект демонстрирует интеграцию трех различных протоколов передачи данных (REST API, SSE и WebSockets) в рамках одного порта на базе **Express** (порт `3000`).

### 📡 Протоколы взаимодействия с инфраструктурой

#### **1. Создание и Удаление инстансов (HTTP REST API)**
*   **[POST]** `http://localhost:3000/` ➔ Команда на создание виртуальной машины.
    *   *Ответ:* `201 Created` ➔ `{ "status": "OK" }`. Сервер сразу отправляет в лог команду `Create command`. Через 10 секунд симуляции железа инстанс физически создается со статусом `stopped`.
*   **[DELETE]** `http://localhost:3000/?id=<id>` ➔ Физическое удаление инстанса из базы данных.
    *   *Ответ:* `200 OK` ➔ `{ "status": "OK" }`.

#### **2. Изменение состояния инстансов (WebSockets)**
Запуск и остановка виртуальных машин требуют двунаправленного триггера. Переключение между состояниями `running` и `stopped` осуществляется отправкой строкового JSON-пакета по адресу `ws://localhost:3000/ws`:
```json
{
  "id": "уникальный-uuid-сервера"
}
```

#### **3. Логирование и Телеметрия (Server-Sent Events — SSE)**
Для вывода потока событий в реальном времени (Worklog) фронтенд подключается к однонаправленному стриму по адресу `http://localhost:3000/sse`. Сервер непрерывно транслирует события с типом `message`, упакованные в ключ `data`:
```json
{
  "id": "<uuid>",
  "info": "Create command | Created | Started | Stopped | Removed",
  "timeStamp": "12:00:00 24.03.2024"
}
```
*Интерфейс фронтенда перехватывает эти триггеры, обновляет консоль оператора и синхронизирует состояние карточек в левой панели.*

## 🚀 Инструкция по локальному запуску

> ⚠️ **ПРИМЕЧАНИЕ ДЛЯ ПРОВЕРЯЮЩЕГО:**
> Проект полностью адаптирован под многопоточную работу. Действия по созданию, запуску и остановке виртуальных машин занимают ровно 10 секунд (задержка эмулируется на бэкенде через `setTimeout`).

### 1. Запуск Backend сервера:
```bash
cd backend
npm install
npm start
```

### 2. Запуск Frontend части:
```bash
cd frontend
npm install
npm start
```
